# Roadmap

## MVP Milestone

Goal: complete the core match organization workflow.

Included:

- Authentication.
- Player profile management.
- Match creation and joining.
- Team balancing.
- Cost split.
- Payment status API.
- Basic React frontend.

Current status: partially complete. Backend is mostly implemented for the MVP workflow; frontend remains in progress.
