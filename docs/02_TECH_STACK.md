# Tech Stack

## Backend

- .NET 8
- ASP.NET Core Web API
- C#
- Dependency Injection built into ASP.NET Core
- Swagger/OpenAPI via Swashbuckle

## Frontend

- React 18
- Vite
- JavaScript
- Tailwind CSS
- Axios-style API client structure in `client/src/api`

## Database

- SQL Server
- Entity Framework Core Code First
- EF Core migrations

## Authentication

- JWT Bearer authentication
- BCrypt password hashing
- Role-based authorization with Admin and Player roles

## Testing Tools

- MSTest
- Moq
- FluentAssertions
- coverlet collector

## Development Tools

- Docker
- Docker Compose
- Swagger UI
- Git
- Node.js/npm for frontend development

## Unknown / To Be Defined

- Production hosting provider.
- CI/CD provider.
- Frontend automated test framework.
- API versioning strategy.
